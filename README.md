## 当前功能

- 本地征程：选将、地图、难度、战斗预览、奖励、营地、集市、奇遇、山河册及结算。战斗继续由无名杀引擎执行。
- 独立 135 张牌堆：85 张基本牌、50 张锦囊，无装备牌和借刀杀人；决斗共 5 张。
- OL 风格武将框、装备与体力显示；支持敌军专属牌面、其他扩展的 DIY 武将图片，以及点按敌将查看技能和难度加成。
- 敌军差异化技能与战法适配；只在征程开局生效的战法不进入商店和过关奖励。
- 绝境难度和噩梦及以上难度的突变；原客户端未包含的服务器判定使用本地规则，不声称完整恢复服务器实现。
- 未开战的普通地图关卡可自由切换；集市在查看关卡并返回地图后仍可进入，保留库存、购买记录和刷新次数。
- 山河册标题连续点击 10 次可开启开发者模式；相邻点击间隔不超过 2 秒，免费解锁战法树及本季已适配的可用战法。

## 源码与运行资源

本仓库提供最新版扩展脚本、样式、版本信息、来源说明和本地装配工具。**GitHub 的 Download ZIP 是源码包，不能直接作为无名杀扩展导入包。**

运行还需要兼容的无名杀引擎和独立提供的匹配资源。以下内容没有随仓库发布，也不受本仓库的 GPL 授权覆盖：

- `assets/`：游戏美术、牌面、头像、字体和动画。

仓库只保留资源路径、文件大小和校验值清单 [local-resources.json](local-resources.json)，方便核对匹配版本。需自行取得并确认所用资源、运行库的授权；本项目未对它们作出开放许可承诺。不包含原版 APK、解包客户端代码、账号信息或玩家存档。

## 开发与本地装配

使用 Node.js 18 或更新版本，无需安装 npm 依赖：

```sh
npm run check
npm run verify:snapshot
```

`check` 检查脚本语法、内部模块路径和版本信息；`verify:snapshot` 额外核对首次发布时的源码校验值，修改代码后不必运行这一项。它们不代替真实引擎内的功能测试。

如果已在本机合法持有匹配的 1.1.2 扩展资源，可在仓库根目录执行：

```sh
node tools/assemble-local.mjs --resources "/path/to/existing/extension/山河图" --output "./dist/山河图"
```

工具先核对所有本地资源的 SHA-256，再创建一个新的扩展目录，将仓库中的源码与这些资源合并。输出目录必须尚不存在；不会修改来源扩展或存档，不会下载资源。`dist/` 已被 Git 忽略，仅供自己的本地安装和验证，不代表其中第三方资源可以公开分发。

退出游戏后，将装配目录放入无名杀的 `extension/山河图`，启用扩展并重启游戏，在模式选择中进入“山河图”。升级前自行备份现有目录及存档。
